プライバシーポリシー

GreenShade studio（以下「当スタジオ」といいます）は、スマートフォン向けゲーム「什么都能擦」（以下「本アプリ」といいます）におけるユーザー情報の取扱いについて、以下のとおりプライバシーポリシーを定めます。

最終更新日：2026年11月4日

1. 本アプリが取り扱う情報

本アプリでは、ゲームの進行状況、所持コイン、解放済みステージ、設定情報などを端末内に保存する場合があります。

これらのゲームデータは、ゲーム機能を提供するために使用され、当スタジオが独自に外部サーバーへ送信または収集するものではありません。

ただし、本アプリでは広告配信のために Google AdMob を利用しています。

Google Mobile Ads SDK などの第三者サービスにより、以下のような情報が自動的に収集または処理される場合があります。

  • IP アドレス
  • アプリの起動、タップ、広告の表示や動画視聴などの操作情報
  • アプリや SDK の動作に関する診断情報
  • Android 広告 ID、App Set ID などの端末識別情報
  • 広告配信、不正利用防止、分析のために必要となるその他の情報

収集される情報の内容は、Google が提供するサービス、ユーザーの端末設定、地域、およびユーザーが行ったプライバシー設定によって異なる場合があります。

2. 情報の利用目的

本アプリおよび本アプリで利用する第三者サービスは、取得した情報を以下の目的で利用する場合があります。

  • 広告の表示および広告配信の最適化
  • 広告の効果測定
  • 不正行為や不正アクセスの防止
  • アプリや広告 SDK の動作確認および品質改善
  • 法令およびプラットフォームポリシーへの対応

3. 広告について

本アプリでは、Google LLC が提供する Google AdMob を利用して広告を表示します。

広告配信のため、Google および Google が利用する広告関連事業者が、ユーザーの端末情報、広告識別子、IP アドレス、広告とのインタラクションなどの情報を処理する場合があります。

一部の地域では、広告や個人データの利用についてユーザーの同意が必要となる場合があります。

その場合、本アプリでは Google User Messaging Platform（UMP）を利用して、ユーザーに必要な情報を提示し、同意またはプライバシーに関する選択を行うための画面を表示する場合があります。

ユーザーが利用できる広告およびプライバシー設定は、地域、端末設定、および Google が提供するサービスによって異なる場合があります。

4. 第三者サービス

本アプリでは、以下の第三者サービスを利用します。

Google AdMob / Google Mobile Ads SDK
提供者：Google LLC

Google User Messaging Platform（UMP）
提供者：Google LLC

これらのサービスにおける情報の取扱いについては、Google が定めるプライバシーポリシーおよび関連規約をご確認ください。

5. 情報の第三者提供

当スタジオが、本アプリを通じて取得したユーザーの個人情報を独自に販売することはありません。

ただし、広告配信などの機能を提供するため、Google AdMob などの第三者サービスによって情報が収集、処理または共有される場合があります。

これらの処理は、各サービス提供者のプライバシーポリシーおよびユーザーの同意設定に基づいて行われます。

6. データの保存

ゲームの進行状況や設定など、本アプリが独自に管理するゲームデータは、原則としてユーザーの端末内に保存されます。

本アプリを削除した場合、これらのローカルデータも削除される場合があります。

広告サービス等によって処理される情報の保存期間については、各サービス提供者のポリシーが適用されます。

7. ユーザーによるプライバシー設定

ユーザーは、端末の設定などを通じて広告 ID のリセットまたは削除などを行える場合があります。

また、法令上必要となる地域では、本アプリ内に表示されるプライバシー設定画面を通じて、広告やデータ利用に関する選択を変更できる場合があります。

8. セキュリティ

当スタジオは、本アプリで取り扱う情報について、適切な方法で管理するよう努めます。

第三者サービスとの通信については、それぞれのサービス提供者が提供するセキュリティ対策が適用されます。

9. 本プライバシーポリシーの変更

本アプリの機能追加、利用するサービスの変更、法令やプラットフォームポリシーの変更などに伴い、本プライバシーポリシーを変更する場合があります。

重要な変更がある場合には、本ページの更新など適切な方法でお知らせします。
